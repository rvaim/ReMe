# ReMe Universal Marketplace

This local marketplace contains `reme-memory` version `0.3.2+universal.local-20260812-0628Z` for Claude Code and Codex.

The plugin provides:

- conservative automatic recall before selected user prompts;
- an OpenAI Responses API gate only for ambiguous prompts;
- ReMe `search` and `read` context injection;
- automatic ReMe memory writing after completed turns;
- one extensible shared LLM configuration at `~/.reme/config/llm.json`;
- Windows and macOS/Linux launchers;
- one Recall-only ReMe skill shared by both hosts.

Read `plugins/reme-memory/README.md` for configuration, installation, security, and troubleshooting.
